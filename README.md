# Jenkins CI/CD Demo

## Objective

This project demonstrates an end-to-end CI/CD pipeline using:

- Java 21
- Spring Boot
- Maven
- GitHub
- Jenkins
- Docker (Later)
- Kubernetes (Later)

---

## Build

```bash
mvn clean package
```

---

## Run

```bash
java -jar target/jenkins-cicd-demo-1.0.0.jar
```

---

## Browser

```
http://localhost:8080
```
